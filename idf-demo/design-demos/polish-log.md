## 第一轮（三方向各自）

### 方向一 · 一张纸

看到的最伤三处：

1. 板头标题「白」以 76 px 细字渲染，缩略时整块像一枚黑色方印，读不出是标题 → 改成「一张纸」62 px。
2. 日程页两个翻月按钮做成 34 px 描边小方块，是这套「无容器」语言里唯一的方框，抢注意力 → 去掉边框，改成 40 px 热区的纯字形。
3. 「编辑 / 删除」9.5 px、日期条数 9.5 px，低于可读底线 → 统一提到 11–12 px；表单字节数补到 11 px。

同时修：日期选择 closeup 底部第二行字段被裁 → 改成一行「已选」摘要；添加页底部补回协议日志入口，填住保存按钮下方的空。

### 方向二 · 日程簿

看到的最伤三处：

1. 添加页标签压在板头说明线上（手机 y=306，标签 y=252，板头 meta 正好 240–255） → 整排下移 24–30 px，删掉那条装饰性的渐变横线。
2. 配对回执面板顶部裁掉了「设备配对」标题（面板 352 高，回执实际需要 ~370） → 面板统一升到 380，日期格从 36 压到 33。
3. 我的页「退出登录」被 tabBar 盖住，只剩一条红线 → 先压缩了版权页（删一行信息、合并一段说明），再发现真正的 bug 见第二轮。

同时修：日程页「编辑/删除」10 px 提到 12 px，时间列 11→12 px，月头信息 12 px。

### 方向三 · 节令

看到的最伤三处：

1. 底排三块面板的标签（y=1054）压在手机 tabBar（y=1028–1078）上 → 板高改成 1560，面板下移到 1140。
2. 配对弹层标题「设备配对」是米色字落在米色卡上，几乎看不见 → `panel-body` 统一继承 `--ink`（三个方向都受益）。

同时修：日历底部补「已选 11月24日 周二 · 15:00」；色卡标签 8–9 px 提到 9–10 px；设备卡去掉挤位置的固件号。

## 第二轮（三方向共有的两处结构问题）

1. **tabBar 下面的内容被吃掉 83 px。** 外壳 `.scroll` 的 `bottom` 是 0，tabBar 绝对定位盖在上面，所有 tab 页最后 83 px 都落在 tabBar 背后——A 的退出登录、B 的版权页、添加页的日志入口都是这样消失的。改成有 tabBar 时 `.scroll{bottom:83px}`。
2. **转发卡片右边被画布裁掉。** 卡片 236 + 聊天底衬 36 = 272，放在 x=1202 时超出 1440。改成无左侧头像、底衬 10 px（总宽 256），B/C 移到 x=1176，A 的板头卡留在 1104。

修完重新截图；三张板的所有关键元素（退出登录、版权行、日志入口、配对标题、转发卡）都完整可见。

### 同步 / 断开的二次确认（2026-11-23）

用户反馈：连接设备后点「同步」「断开」会直接执行，没有确认。现在两处都先 `wx.showModal`：

- 同步：「同步日程 / 将把云端与设备上的日程双向补齐，过程中请让设备保持在附近。要现在同步吗？」确认后才跑 `syncDevice`；如果确认时设备已断开，只提示「设备已断开」。
- 断开：「断开设备 / 断开后设备会停止同步，日程仍保存在云端；需要时重新扫描连接即可。」确认后才 `ble.disconnect()`。
- 锁屏休眠本来就有确认，未改。

补了两条回归测试（同步先出确认、断开取消不执行）；`node --test` 114 pass。
