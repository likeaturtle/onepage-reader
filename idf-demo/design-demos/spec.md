# 设计 spec · 墨程CalCal 小程序样式改版

## 这是什么

墨程CalCal 是 OnePage C61 墨水屏日历的微信小程序客户端。设备挂在墙上或立在桌上，
显示月历、当天日程和锁屏预告；手机负责登录、连接、录入、语音解析、云端与设备同步。
这次不改功能，只改**界面语言与信息层级**：让手机端看起来是这台墨水屏的配套纸页，
而不是一套通用的圆角卡片模板。

## 受众与场景

- 买下这台墨水屏日程表的人：上班族、学生家长、需要把日程「放到看得见的地方」的人。
- 使用场景：早上出门前扫一眼；坐在工位上想起一件事，打开小程序说一句就存进去；
  在会议室里用手机改一条日程，回座位时设备已经刷新。
- 他们不追求炫技，追求**安静、可信、快**。界面的第一印象应该是纸和墨，而不是 App。

## 核心信息（按优先级）

1. 今天 / 选中的日期，和设备现在是「已连接」还是「云端」。
2. 加一条日程：说一句，或填四个字段，保存。
3. 这个月已经有什么：按天排的日程、时间、备注。
4. 设备归属与账号：我的设备、绑定/解绑、退出登录。
5. 技术状态（固件、协议、日志）收在下面，需要时再看。

## 情调

克制、安静、可依赖。像一本用旧的日程本，不是广告。允许有一处锋利：
一个巨大的日期数字、一条实心墨条、一列日期栏，或一个会随月份换色的头。

## 共同的界面调整（三版都做，属于信息层级而非功能）

- **添加页把「加一条日程」提到第一屏**：日期抬头 → 设备一行状态 → 语音一句话入口 →
  日期/时间/标题/备注 → 保存。设备未连接时才展开扫描面板；已连接时只留一行状态和
  同步/休眠/断开三个文字动作。协议日志留在页尾。
- **语音不再是独立大卡片**：保留文字输入框和按住说话，但压缩成一条「说一句」的带子，
  解析按钮跟随，录音进度仍画在按住区域上。
- **日程页按月分组不变**，但日与日之间要有明确的节奏差异（日期重、事件轻），
  编辑/删除不再抢标题。
- **我的页**头像/昵称保留，设备列表、信息、说明按「这台设备是谁的」组织，退出登录
  不抢主视觉。
- 登录页保留微信一键登录与说明，不要求先授权蓝牙。
- 所有状态（未连接、扫描中、空日程、录音中、配对错误）在三版里都要有位置。

## 输出格式

- 三张方向展示板：1440 宽 HTML，每张 4 台手机（登录 / 添加 / 日程 / 我的，375×812）＋
  3 块 1:1 细节面板（表单与月历、配对弹层、方向自己的系统样张）＋ 一张 5:4 转发卡片。
- 定稿后落到真实小程序：WXML/WXSS/JSON 改动，JS 逻辑不动（除非重构必需的 class）。
- 交付前用 Chrome 无头浏览器截图逐屏看，至少两轮打磨。

## 已知约束

- 375 宽 / 750 rpx；正文 ≥12 px；触控 ≥44 px；胶囊不遮挡。
- 系统字体（苹方 / 宋体 / Menlo），不下载字体。
- 主包 2 MB；无照片；图标为内联 SVG（实现时 tabBar 用 81×81 PNG）。
- 原生 tabBar 三项，无图标 → 这次补一套线性图标（实现时生成 PNG）。
- 分享卡片当前无 `onShareAppMessage`，按概念稿呈现并标注。

## 素材需求

没有摄影素材。主角是：**墨程的标志（真实 PNG）**、**墨水屏月历/锁屏预览（真实渲染）**、
**日期数字与表格线**、**季节色（从纸墨推导）**。界面里不出现 emoji、手绘人像或灰色占位块；
头像用首字母圆片，图标用线性 SVG，月份/日期用系统宋体的数字。
