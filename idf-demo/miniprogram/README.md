# 墨程CalCal · 微信小程序

这是 `web/index.html` 之外的另一套客户端：原生微信小程序（墨程CalCal），Android / iOS 都能用 BLE
连接 `Mochen CalCal` 设备。导入开发者工具、配置 AppID/.env 的完整步骤见
[`微信小程序配置说明.md`](../微信小程序配置说明.md)。

**固件、BLE 协议和现有网页都没有改动**，小程序复用同一套 JSON 行协议
（[`../docs/ble-protocol.md`](../docs/ble-protocol.md)）。

## 功能

- 微信登录（`wx.login` → 服务端 `code2session`），登录态本地持久化；
- 开发模式下免 AppID 登录，方便先在模拟器/真机跑通蓝牙；
- **云端日程**：登录后日程保存在服务端，没带设备也能在手机上查看、添加、删除；
- 扫描并连接设备，自动同步时间；连接后云端与设备双向补齐；
- 添加、删除日程，锁屏休眠，查看固件/设备时间/协议日志；
- 未连接设备时仍可添加/删除，只给轻提示（toast/说明），不强制先连接；
- 头像与昵称（头像上传到自己的服务，不经过第三方）。

BLE 连接本身不需要登录；但本版本的主页面要求登录，因为日程列表来自“我的云端日程”。
登录不再只是头像昵称——它决定看到哪一份日程。

第一次使用云端功能时，需要先连接一次设备，把设备上已有的日程导入云端；之后不带设备
也能在手机上看。

## 快速开始

### 1. 启动登录服务

```bash
cd idf-demo/server
cp .env.example .env
npm start
# [server] listening on http://0.0.0.0:8787
```

本地开发保持 `.env` 里的 `ALLOW_DEV_LOGIN=1`，先不填 `WX_APPID` / `WX_SECRET` 也能登录。

### 2. 导入小程序

1. 打开微信开发者工具 → 导入项目，目录选 `idf-demo/miniprogram`；
2. AppID 可以先用「测试号」，或把自己的 AppID 填进 `project.config.json`；
3. 右上角「详情 → 本地设置」勾选 **不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**；
4. 如果手机真机调试，把 [`config.js`](config.js) 的 `apiBase` 改成电脑的局域网地址
   （如 `http://192.168.1.20:8787`），手机和电脑要在同一 Wi-Fi；
   开发者工具里用 `http://127.0.0.1:8787` 即可。

### 3. 登录

- 点「开发模式登录」：走 `POST /api/login {"dev":true}`，不需要微信 AppID；
- 或者配置好 `WX_APPID` / `WX_SECRET` 后点「微信一键登录」。

### 4. 连接设备

1. 按设备 POWER 键唤醒；
2. 点「扫描设备」，选择 `Mochen CalCal`（找不到时打开「显示全部蓝牙设备」）；
3. 连接成功后自动同步时间，并执行一次“云端 ↔ 设备”补齐；
4. 没连接设备时添加/删除只改云端；连接后点「同步」或重新连接即可落到设备；
5. 「锁屏休眠」等价于网页上的「让设备锁屏」。

真机必须用「真机调试」或预览，**开发者工具模拟器不支持 BLE**。

## 正式环境

1. 在微信公众平台配置 `request 合法域名` 为登录服务的 HTTPS 域名；
2. 服务端 `.env` 填 `WX_APPID`、`WX_SECRET`、随机 `SESSION_SECRET`，并把
   `ALLOW_DEV_LOGIN` 设为 `0`；
3. `config.js` 的 `apiBase` 改为 `https://你的域名`，`devLogin` 改为 `false`；
4. 头像使用 `<image>` 加载服务端 `/avatars/...`，如果使用独立图片域名，还要配置
   `downloadFile 合法域名`（或直接把头像域名放在同一 API 域名下，本项目默认如此）。

## 云端与设备的同步

当前是**双向同步**：

- 手机端新增/删除先写云端，所以没带设备时也能看；
- 连接设备后：设备有、云端没有 → 导入云端；云端有、设备没有 → 推送到设备；
- **设备上用按键删除的当前窗口内事件，同步时也会删除云端记录**；
- 如果设备上一条都不剩（可能是设备重置），或一次消失 3 条以上，会弹窗确认
  “删除云端”还是“恢复设备”，防止设备 NVS 被清空时误删云端；
- 设备返回的 `done.n` 与收到的条目数不一致时中止同步，避免把丢包误判成删除；
- 只同步“今天 −7 天 ~ 今天 +120 天”的事件，避免占满设备 NVS；云端保留全部；
- 一个账号按一台设备设计（固件没有设备序列号）。

同步逻辑在 [`pages/index/index.js`](pages/index/index.js) 的 `syncDevice()`，对应的
离线单测在 [`test/sync.mock.test.js`](test/sync.mock.test.js)。

## BLE 实现要点

- 服务/特征 UUID 与网页、固件保持一致：
  service `6f6e6570-6167-6531-6361-6c656e646172`，RX `...0001`，TX `...0002`；
- 写入按 20 字节分片，兼容默认 MTU 23；
- 通知先按字节缓冲，遇到 `\n` 再按 UTF-8 解码，避免多字节字符跨包被截断；
- 扫描按一次约 5 秒的窗口执行，结束后自动停止；扫描过程中列表按首次发现顺序追加，
  停止后再按信号强度排序一次，避免 RSSI 变化导致列表持续跳动；
- 同一时间只允许一条命令在途，`command()` 内部串行化并等待 ack / `ev:"done"`；
- 扫描不依赖广播里的 service UUID（iOS 上经常取不到），默认按名字包含 `Mochen`
  过滤，连上后再校验 service UUID；
- `deviceId` 在 iOS 上是系统分配的 UUID、Android 上是 MAC，不能硬编码，重连前重新扫描；
- 小程序切后台/锁屏后系统会挂起 BLE，回到前台需要重新连接，这是平台限制。

## 登录接口

见 [`../server/README.md`](../server/README.md)。小程序只接触：

| 方法 | 路径 | 作用 |
|:---|:---|:---|
| POST | `/api/login` | `{code}` 微信登录，或 `{dev:true}` 开发登录；返回 `{token,user}` |
| GET | `/api/me` | 读取当前用户 |
| POST | `/api/me` | 修改昵称 `{nickname}` |
| POST | `/api/me/avatar` | 上传头像 `{data:"data:image/png;base64,..."}` |
| GET | `/api/events` | 云端日程列表，支持 `from`/`to`/`includeDeleted` |
| POST | `/api/events` | 新增云端日程；返回 `{event}` |
| DELETE | `/api/events/:id` | 软删除，保留 tombstone |
| POST | `/api/events/:id/device` | 关联设备上的数字 id |
| POST | `/api/events/:id/purge` | 设备删除成功后物理删除云端记录 |
| POST | `/api/logout` | 客户端丢弃 token（服务端无状态） |

`WX_SECRET` 只存在服务端，绝不放进小程序代码。

# 小程序协议 + 同步逻辑单测（不需要微信环境）

# 登录服务单测

真机清单：

1. 冷启动 → 未登录跳登录页；登录后进入「日程」；
2. 关闭再打开小程序，登录态仍在；
3. 不连接设备，添加一条日程 → 杀进程重开 → 仍能在云端列表看到；
4. 扫描 → 连接 → 自动同步时间，云端日程被推到设备；
5. 在网页/设备端新增一条，连接后同步 → 云端出现；
6. 删除一条日程，设备列表刷新；离线删除后连接设备，设备上的也被删掉；
7. 锁屏休眠 → 设备亮锁屏 → 按 POWER 唤醒后重新连接；
7. iOS 拒绝蓝牙权限后给出可理解的提示；去系统设置授权后能恢复；
9. 退出登录后再进入小程序，回到登录页。

## 已知限制

- 小程序无法后台常驻 BLE，不能做「后台自动同步」；同步发生在打开页面/连接设备时；
- 设备重置/批量删除时会弹窗确认，自动同步无法在没有用户确认的情况下删除大量云端数据；
- 只同步“今天 −7 天 ~ 今天 +120 天”的日程到设备，更远的日程只在云端可见；
- 同步窗口外的设备删除不会被检测到（避免把设备自动清理的历史日程误删）；
- 设备没有配对/绑定，任何登录用户连上设备都能读写日程；如果要做「设备归属」，
  需要在固件里加绑定/鉴权，当前协议没有；
- 单用户端到端流程已经打通，但多用户共享同一台设备时日程不做隔离；
- 小程序发布需要注册主体并过审；「开发模式登录」只用于本地调试。

## 故障排查

| 现象 | 原因 / 处理 |
|:---|:---|
| 点登录报「无法连接服务器」 | `apiBase` 不对；真机不能用 `127.0.0.1`；检查手机与电脑同一网段、防火墙 |
| 微信登录报 AppID 错误 | `.env` 的 `WX_APPID`/`WX_SECRET` 与小程序 AppID 不一致；或用了测试号 |
| 扫描不到设备 | 设备在深睡（按 POWER）；打开「显示全部蓝牙设备」；iOS 检查微信蓝牙权限 |
| 连接后收不到通知 | TX 的 CCCD 未订阅；重新连接；查看页面底部协议日志 |
| 添加报 `calendar full` | 设备 96 条上限且没有可清理的过去日程，先删几条 |
| 手机端有日程但设备没有 | 连接设备后点「同步」；确认事件日期在 −7 ~ +120 天窗口内 |
| 设备端删掉的日程云端还在 | 连接设备后点「同步」；若设备为空或一次删除多条，会弹窗确认删除云端 |
| 标题被截断 | 固件限制标题 47 字节、备注 95 字节；小程序有字节计数提示 |
